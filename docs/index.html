#Why howto

A pure "question in, command out" program — your shell does everything else.

⌨️Pre-typed, not executed

The answer lands at your own prompt via the shell wrapper. Enter runs it, your line editor edits it, Ctrl-C discards it. Nothing ever runs on its own.

🧭Context-aware

The prompt includes your OS, shell, installed binaries, and project markers — so "kill port 3000" answers with lsof on macOS and fuser where that's what exists.

🛡️Safety built in

Risky commands show a ⚠ reason. A local blocklist catches rm -rf /-class commands regardless of what the model says, and high-danger commands are never pre-typed.

🤖Agent-friendly

stdout carries only the command (or JSON with -j); everything else goes to stderr. It never blocks on input, and exit codes are an API: 0 ok · 1 error · 2 no sensible command.

🔢Numbered recall

Alternatives are numbered. howto 2 loads option [2] from the last answer, and howto --last re-shows it — no API call, no copy-paste.

⚡Fast & small

A single Rust binary using Claude Haiku by default — quick, cheap answers with no async runtime and no daemon.

#Get started

Three steps from zero to commands at your prompt.

1

Install

Prebuilt for macOS and Linux. With Rust installed: cargo install --path . from a checkout.

curl -LsSf https://github.com/C0ldSmi1e/howto/releases/latest/download/howto-installer.sh | sh
2

Set your API key

Get one at platform.claude.com.

export ANTHROPIC_API_KEY=sk-ant-...
3

Add the shell wrapper

This is what puts commands at your prompt. Without it, howto prints the command instead of typing it for you.

# ~/.zshrc   (bash: --init bash)
eval "$(howto --init zsh)"

#Usage

No quotes needed — everything after howto is your question.

howto compress this folder into a tar.gz
howto 2                                   # use option [2] from the last answer
howto --last                              # show the last answer again
howto --explain find files changed today  # part-by-part breakdown
howto -p free up disk space               # bare command on stdout (for scripts)
howto -j convert a.png to webp            # structured JSON (for agents)
FlagWhat it does
-p, --printbare command on stdout only
-j, --jsonstructured JSON result
--explainpart-by-part breakdown
--lastre-show the last answer (no API call)
--init <shell>print the shell wrapper (zsh, bash)
--configconfig path and resolved settings
-v, --verbosecontext, model, latency on stderr

#Safety

Designed so the dangerous path is always the deliberate one.

Nothing runs on its own

The binary never executes anything. A command only runs when you press Enter at your own prompt.

Local blocklist

An escalate-only regex blocklist catches rm -rf /, dd of=/dev/, mkfs, fork bombs, and curl | sh patterns — regardless of what the model classified.

High danger, high friction

High-danger commands are never pre-typed at your prompt. They're shown numbered, and typing howto 1 is the deliberate act that loads one.
